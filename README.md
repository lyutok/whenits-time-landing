# Day to Night Story

Create a completely new landing page for my iOS app “WhenItsTime”.
you can use any libraries if you find it can improve UI
like GSAP + Lenis + Lucide React + Tailwind CSS

This is an alternative visual concept to explore.

DO NOT reuse the structure, visual language, or component style of the existing landing page.

The existing landing page is too conventional and feels like a SaaS/productivity website. I want this version to feel like a small, beautiful, memorable consumer app.

==================================================

THE CREATIVE CONCEPT

==================================================

The entire website should be built around one idea:

“A day can look completely different depending on where you are.”

WhenItsTime helps people understand the relationship between their time and someone else's time.

The visual metaphor is:

MORNING → DAY → EVENING → NIGHT

The website should feel like moving through a day.

Imagine a beautiful transition between daylight and evening as the user scrolls.

The design should subtly evolve as the page progresses.

It should feel almost cinematic.

Not a literal animation-heavy website.

More like:

- Apple product storytelling

- modern editorial website

- beautiful indie iOS app

- subtle atmospheric gradients

- light changing throughout the page

The user should want to keep scrolling simply because the website feels pleasant.

Left:

WhenItsTime logo + name

Features

Pro

Get the app

The navigation should be transparent or very subtle at the top and adapt naturally as the page changes.

==================================================

HERO — “IS NOW A GOOD TIME?”

==================================================

The hero should be visually striking.

Headline:

“Is now a good time?”

This should be the dominant text.

Below:

“WhenItsTime helps you find out.”

Then a very short explanation:

“See local time, working hours, and the best moments to connect — wherever you are.”

Primary CTA:

Download on the App Store

Secondary small text:

Free to start

==================================================

HERO VISUAL

==================================================

Do NOT use the conventional:

text left + two phones right.

Instead, create a large atmospheric composition.

Use the strongest WhenItsTime screenshot prominently.

The phone should appear to float within a soft environment inspired by daylight.

Behind it, create a very subtle circular gradient representing the sun/horizon.

Possible visual language:

a huge soft circle partially visible behind the phone,

like a sunrise.

The app screenshot is the object sitting inside this environment.

Use generous empty space.

The result should feel like a product advertisement.

Not like a website template.

==================================================

SECTION 2 — TWO PLACES, ONE MOMENT

==================================================

As the user scrolls, transition from bright daylight toward a slightly deeper tone.

Headline:

“Your afternoon might be their evening.”

Keep the copy very short.

Example:

“Time zones tell you what time it is.

WhenItsTime helps you understand what that means.”

Create a visual showing two different moments of the day.

Do not use a generic world map.

Instead use:

- two abstract circles

- subtle sun/moon shapes

- two local times

- elegant typography

The design should make the relationship between two locations visually obvious.

==================================================

SECTION 3 — FIND THE MOMENT

==================================================

Now introduce the main feature.

Headline:

“Find the moment that works.”

Use:

assets/screen-hero-overlap.png

Make the screenshot large.

Allow it to visually overlap the surrounding layout.

Copy:

“See when your schedules overlap and find a better moment to call, meet, or message.”

Keep the copy short.

The screenshot should be the main thing people look at.

==================================================

SECTION 4 — FOLLOW THE DAY

==================================================

Use:

assets/screen-explore.png

The background should now subtly shift.

Headline:

“See how their day is going.”

Supporting text:

“Keep the places that matter to you in view and see their local time and working hours at a glance.”

Use elegant typography and lots of whitespace.

Do not use a feature card.

Do not put the screenshot inside a generic white card.

Let the screenshot exist naturally within the page.

==================================================

SECTION 5 — WHEN THEY'RE AVAILABLE

==================================================

Use:

assets/screen-working-hours.png

Headline:

“Know when they're actually available.”

Supporting text:

“Set working hours for each location and instantly see whether now is a good time — or when the next good window begins.”

Visual direction:

The surrounding background should feel like late afternoon.

Use a subtle warm gradient.

The screenshot should feel like it is sitting inside this changing light.

==================================================

SECTION 6 — LET THE APP REMEMBER

==================================================

Now transition toward evening.

Use:

assets/screen-notify-me.png

and

assets/screen-reminders.png

Headline:

“You don't have to remember.”

Supporting text:

“Set a reminder for the moment that matters and let WhenItsTime handle the time-zone math.”

This section should feel calmer and darker than the beginning.

Think evening.

Do not make it visually heavy.

==================================================

SECTION 7 — THE HUMAN MOMENT

==================================================

This is an important emotional section.

No feature cards.

No technical explanation.

Large typography:

“Because sometimes,

you just want to call someone

at the right time.”

Then small supporting text:

“Friends. Family. Clients. People who live somewhere else.”

This should be one of the most beautiful sections of the page.

Give it lots of whitespace.

Use the app icon or a very subtle visual element.

==================================================

SECTION 8 — WHO IT'S FOR

==================================================

Do not make this a standard four-card grid.

Instead use a flowing list / editorial layout.

For example:

FOR THE FRIEND

who moved away.

FOR THE FAMILY

on the other side of the world.

FOR THE CLIENT

who works nine hours behind you.

FOR THE TRIP

you're planning across time zones.

FOR YOU

when you just don't want to think about the clock.

Use typography and spacing to make this feel like part of the story.

==================================================

SECTION 9 — PRO

==================================================

Now introduce the paid version without breaking the visual atmosphere.

Headline:

“Make it part of your day.”

Brief explanation:

“Keep more places, explore more cities, and never run out of reminders.”

Use two very clean pricing choices:

Monthly

$2.99 / month

Yearly

$19.99 / year

Lifetime

$39.99 once

Also show Free vs Pro differences clearly, but keep the presentation compact.

Free:

- 2 main locations

- Switch locations

- Working Hours

- Find Time

- Best Overlap

- Explore up to 3 cities

- One-time reminders

- Repeating reminders

- Up to 3 active reminders

Pro:

Everything in Free, plus:

- Unlimited cities in Explore

- Unlimited active reminders

Do not use aggressive subscription marketing.

No:

“BEST VALUE”

“LIMITED OFFER”

“50% OFF”

countdown timers

fake urgency

==================================================

FINAL SECTION — NIGHT

==================================================

The page should gradually arrive at its darkest point.

A beautiful deep-blue / night background.

Headline:

“Whenever you need to know,

WhenItsTime.”

Or:

“Know when to connect.”

Supporting text:

“Less guessing.

Less time-zone math.

Just the right time.”

App Store button.

Place the app icon subtly beside or above the CTA.

The final section should feel peaceful.

Like the end of a day.

==================================================

VISUAL SYSTEM

==================================================

The visual system should evolve throughout the page.

Beginning:

warm white / very pale blue / morning

Middle:

soft blue / teal / warm daylight

Later:

warm sunset / peach / muted orange

End:

deep blue / evening / night

IMPORTANT:

The transitions must be subtle.

Do not turn the website into a rainbow gradient website.

The colors should feel natural and atmospheric.

Think:

sky

sunlight

horizon

evening

rather than:

neon gradients

startup gradients

gaming UI

==================================================

TYPOGRAPHY

==================================================

Typography is extremely important.

Use a modern, elegant sans-serif.

Large headlines should feel confident and editorial.

Some sections can use very large typography, even 72–100px on desktop.

Keep body text short.

Avoid huge paragraphs.

Use whitespace as part of the design.

The page should feel sophisticated even though the product is simple.

==================================================

SCREENSHOT PRESENTATION

==================================================

The screenshots are the stars.

Do not put every screenshot inside identical cards.

Vary their presentation:

- one large floating phone

- one screenshot partially cropped

- one centered phone

- two screenshots slightly overlapping

- one phone emerging from the edge of the viewport

Use subtle shadows.

Avoid thick borders.

Avoid generic 3D phone mockups.

The actual iPhone screenshot should remain crisp and readable.

==================================================

MOTION

==================================================

Use subtle scroll-based motion.

Examples:

- phones move slightly as they enter the viewport

- background gradient slowly changes

- large circles move very slowly

- text fades in

- screenshots gently translate vertically

- day/night atmosphere gradually changes

Keep animation extremely smooth.

No excessive bouncing.

No flashy animations.

No distracting effects.

Respect prefers-reduced-motion.

==================================================

LAYOUT PRINCIPLES

==================================================

Do NOT build the page from repeated cards.

Do NOT use a standard:

Hero → Features grid → Pricing cards → Testimonials → Footer

template.

The page should feel like one continuous visual story.

Sections should flow into each other.

Use:

- full-width backgrounds

- oversized typography

- overlapping elements

- generous whitespace

- atmospheric gradients

- editorial composition

- asymmetry

The page should look intentionally art-directed.

==================================================

MOBILE

==================================================

Design mobile separately.

Do not simply stack desktop elements.

On mobile:

- typography should remain expressive

- screenshots should remain large enough to understand

- atmospheric backgrounds should still work

- horizontal overflow must never occur

- animations should be lighter

- CTA should remain obvious

==================================================

COPY STYLE

==================================================

Copy should be:

short

human

warm

confident

simple

Avoid corporate language such as:

“Optimize your global communication workflow.”

“Maximize cross-time-zone productivity.”

“Streamline international collaboration.”

Never describe WhenItsTime like enterprise software.

Instead use language like:

“Is now a good time?”

“Your afternoon might be their evening.”

“Find the moment that works.”

“Know when they're actually available.”

“You don't have to remember.”

“Sometimes you just want to call someone at the right time.”

==================================================

TECHNICAL

==================================================

Build using clean React components.

Use the supplied assets.

Make all App Store buttons use a single clearly defined placeholder URL.

Use semantic HTML.

Optimize image loading.

Lazy-load below-the-fold screenshots.

Ensure excellent responsive behavior.

Ensure accessibility.

Respect prefers-reduced-motion.

Keep dependencies minimal.

Do not invent app functionality.

Do not change the app screenshots.

==================================================

FINAL CREATIVE TEST

==================================================

Before considering the design finished, ask:

Does this feel like a website about TIME?

Does the page visually move from day toward night?

Does it feel emotional rather than corporate?

Does someone understand the problem within 5 seconds?

Do the real app screenshots feel like the hero of the story?

Would I actually want to keep scrolling?

Would this make me curious enough to download the app?

If the answer is no, simplify the design rather than adding more UI.

The final result should feel like:

“A beautiful little app about being in the right moment.”

Not:

“A time-zone SaaS landing page.”
